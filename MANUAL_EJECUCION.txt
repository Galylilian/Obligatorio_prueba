0. QUE HACE ESTE PROYECTO
================================================================================

Clasifica imagenes en dos clases:
  - fall      → persona caida
  - not_fall  → situacion normal

Flujo de datos:
  Roboflow (internet)
       |
       v  [Paso 1: download]
  data/raw/                    (DS1 + DS2 por separado)
       |
       v  [Paso 2: fuse]
  data/fused/                  (dataset unificado, train/valid/test)
       |
       v  [Paso 3: extract_features]
  data/metadata/*.csv          (metadata + features tabulares)
       |
       v  [Paso 4: train]
  models/resnet18_best.pth     (modelo entrenado)
  models/label_encoder.pkl     (mapeo indice -> etiqueta)
       |
       v  [Paso 5: evaluate]
  metricas en consola
       |
       v  [Pasos 6-7: API + Streamlit]
  inferencia en vivo

3. PASO 1 — DESCARGAR DATASETS (ROBOFLOW)
================================================================================

Script:  scripts/download_dataset.py
Entrada: ROBOFLOW_API_KEY en .env
Salida:  data/raw/fall-detection-raskl/
         data/raw/fa-nunl5/

Comando:

  - Descarga DS1: fall-detection-raskl (v2)

================================================================================
4. PASO 2 — FUSIONAR DATASETS
================================================================================

Script:  scripts/fuse_datasets.py
Logica:  src/preprocessing/fusion.py
Entrada: data/raw/ (DS1 + DS2)
Salida:  data/fused/{train,valid,test}/{fall,not_fall}/
         data/metadata/fall_dataset_fused_metadata.csv

Comando:
  .\.venv\Scripts\python.exe scripts\fuse_datasets.py

Que hace internamente:
  - Copia imagenes de DS1 y DS2 a data/fused/
  - Renombra con prefijo DS1_ o DS2_
  - Normaliza etiquetas a fall / not_fall
  - Genera CSV con: split, label, path, filename, dataset_source

Verificar:
  (Get-ChildItem data\fused -Recurse -File | Measure-Object).Count
  Import-Csv data\metadata\fall_dataset_fused_metadata.csv | Measure-Object

  Resultado esperado (aprox.):
    ~1373 imagenes
    ~1373 filas en el CSV

  Balance esperado en consola:
    train: fall~550, not_fall~514
    valid: fall~100, not_fall~77
    test:  fall~73,  not_fall~59

Tiempo estimado: 1-3 minutos.

5. PASO 3 — EXTRAER FEATURES TABULARES
================================================================================

Script:  scripts/extract_features.py
Logica:  src/features/tabular_features.py
Entrada: data/metadata/fall_dataset_fused_metadata.csv
         data/fused/ (imagenes)
Salida:  Mismo CSV enriquecido con columnas de features
         (brightness, contrast, aspect_ratio, etc.)

Comando:

Que hace:

  - Los agrega al CSV de metadata
  - Si ya existen, imprime "Features tabulares ya presentes" y termina

Verificar:

  $csv[0].PSObject.Properties.Name -match "brightness"

  Debe listar columnas de features.

Nota:
  El entrenamiento actual (ResNet18) NO usa estas features.
  Sirven para el EDA del notebook y analisis del informe.

Tiempo estimado: 2-5 minutos.


================================================================================
6. PASO 4 — ENTRENAR MODELO
================================================================================

Modulo:  src/core/train.py
Entrada: data/fused/ (train + valid)
Salida:  models/resnet18_best.pth
         models/label_encoder.pkl

Comando:
  .\.venv\Scripts\python.exe -m src.core.train

Que hace internamente:
  1. Carga imagenes con ImageFolder (src/preprocessing/dataset.py)
  2. Aplica transforms: resize 224x224, augmentacion en train
  3. Crea ResNet18 preentrenada (src/core/model.py)
  4. Congela capas base, entrena solo la ultima capa (transfer learning)
  5. Entrena 5 epocas (configurable en src/settings/config.py)
  6. Guarda el modelo con mejor val_acc

Salida esperada en consola (ejemplo):
  Dispositivo: cpu  (o cuda si hay GPU)
  Clases: ['fall', 'not_fall']
  Epoch 1/5 | train_loss=0.60xx | val_loss=0.59xx | val_acc=0.67xx
  ...
  Epoch 4/5 | ... | val_acc=0.83xx
    -> Mejor modelo guardado (val_acc=0.83xx)
  Modelo guardado en: models/resnet18_best.pth

Verificar:
  Test-Path models\resnet18_best.pth
  Test-Path models\label_encoder.pkl

Tiempo estimado:
  CPU: 8-30 minutos
  GPU: 2-5 minutos

Parametros editables (.env o src/settings/config.py):
  NUM_EPOCHS=5
  BATCH_SIZE=32
  LEARNING_RATE=0.001

13. SOLUCION DE PROBLEMAS
================================================================================

Error: "No module named 'urllib3'" (o cualquier modulo)
  Causa: usaste python del sistema en lugar del .venv
  Solucion: .\.venv\Scripts\python.exe en todos los comandos

Error: "Falta ROBOFLOW_API_KEY en .env"
  Causa: .env no configurado
  Solucion: copy .env.example .env y pegar tu API key

Error: SSL / certificado al descargar Roboflow
  Causa: problema de certificados en la red/PC
  Solucion: el script download_dataset.py ya tiene workaround SSL;
           si falla, verificar firewall o VPN

Error: "El paquete ipykernel no esta instalado"
  Causa: kernel del notebook apunta a otro Python
  Solucion: seleccionar kernel "Python (obligatorio)" o .venv\Scripts\python.exe

Error: puerto 8080 ocupado
  Causa: API ya corriendo en otra terminal
  Solucion: usar la instancia existente o cerrar el proceso anterior

Error: Streamlit no muestra prediccion
  Causa: API no esta levantada
  Solucion: ejecutar Paso 6 antes del Paso 7

Error: UnicodeEncodeError en evaluate (Windows)
  Causa: caracteres especiales en print
  Solucion: ya corregido en src/core/evaluate.py (usar ASCII en mensajes)

Entrenamiento muy lento
  Normal en CPU. Reducir epocas temporalmente: NUM_EPOCHS=2 en .env
